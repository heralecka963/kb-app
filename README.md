# kb-app

Veřejné stránky aplikace „Kontrola plateb“ (Heralecká 963 s.r.o.) pro registraci u Komerční banky: návratová adresa (`callback.html`), podmínky, ochrana údajů a logo.
Žádný kód pro banku, žádné přístupové údaje ani data – ty jsou v soukromém repozitáři `bankovni-data`.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
